# Weather

A Weather App is a frontend web application that displays real-time weather information for a selected location. It uses HTML, CSS, and JavaScript to create the user interface and interact with a weather API.

The user can enter a city name, and the application sends a request to a weather API. The API returns information such as temperature, humidity, wind speed, weather condition, and location. JavaScript processes this data and dynamically updates the webpage without requiring a page refresh.

Main Frontend Features
🌤️ Search weather by city
🌡️ Display current temperature
💧 Show humidity
💨 Show wind speed
☁️ Display weather condition and icon
📍 Show city and country
🔄 Fetch updated weather data from an API
📱 Responsive design for mobile and desktop
⚠️ Handle invalid city names and API errors
Technologies Used

HTML – Creates the structure of the weather application.
CSS – Handles layout, colors, typography, animations, and responsive design.
JavaScript – Handles user interaction, API requests, data processing, and dynamic content updates.
Weather API – Provides real-time weather data.
